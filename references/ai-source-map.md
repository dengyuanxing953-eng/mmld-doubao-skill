# 七产品来源地图

版本：2026-09-28。与 platform-registry.json 一起使用。不是固定白名单、算法权重或收录承诺。

## 如何读证据

| 标签 | 能证明什么 | 不能证明什么 |
|---|---|---|
| observed_url | 特定日期、问题、模式的来源面板中看到可定位链接 | 网站内容真实、支撑每句回答、所有行业的权重 |
| observed_label | 面板出现站点名或标题，未取到原链接 | 直接URL、精确域名、独立事件数 |
| official_consumer | 官方消费者协议或帮助称有某能力 | 独立测量已证明效果 |
| official_api | 开发者产品可配置或返回的来源 | 消费者App默认同一线路 |
| historical_study | 已公开研究在既定时点和问题中观察到来源 | 当前版本、其他主题也如此 |
| self_report | AI在对话中自述的来源类别 | 训练清单、内部机制或平台正式政策 |
| unknown | 没有足够证据 | 不可引用、没有收录或永远不支持 |

本轮模型自述共同提到训练知识、用户材料和联网检索；没有产品披露完整站点排序。下面保留有名字的平台；没有具体站名的产品明确留空，不用别家生态补齐。
