# GEO 来源监测

不绑定Google Antigravity、Hermes或某个不存在的预览模型。使用当前环境真实可用且获允许的工具；没有浏览器权限也可以先分析已保存记录。

## 触发与模式

- 来源研究：输出实际URL、来源标题、官方范围、模型自述四类证据，不能混成权重榜。
- 内容效果复测：沿用自然问题、模式、账号/记忆条件；检查目标内容是否真正支持正文。
- 定时监控：只有用户请求持续/定时工作时，使用宿主支持的调度工具；一次分析不能擅自建cron。
- 竞品比较：用同题同条件记录，不以有利样本替换零命中或不利答案。
- 购物/Feed等专项：只在任务涉及它时核对协议与页面，不默认生成无依据的0—100评分。

## 采集契约

读 [观测契约](references/observations.md)。每条记录产品、surface、模式、时间、问题ID、prompt_kind、回答状态、来源捕获完整性及来源支持关系。私密原始对话保留本地，公开技能只保留脱敏平台级方法。

先读当前页面再决定操作。来源未展开时capture为not_captured；验证码导致无答案时status为blocked，不能计作负面、零引用或自然推荐未命中。新的有效回答更新同一观测ID的更新时间，重新生成统计，不保留过期blocked派生值。

将消费者产品与基础模型区分：元宝里DeepSeek不等于DeepSeek官网；秘塔/知乎直答不能自动算作两个独立基础模型。产品不通时保留阻塞，不换另一平台答案充数。

## 汇总

~~~sh
python scripts/aggregate_sources.py observations.json
~~~

脚本只读本地JSON，不联网、不定时、不公开上传。输出有效/阻塞数、完整/部分捕获数、原链接出现次数、去重URL、平台/域名覆盖与已核对正文支持数。候选来源卡不算正文采用；API与自然消费端分别成组。

样本量、跨日与记忆独立性要随结果报告。同日多次只说明当日波动。跨日重复是稳定性评估的必要资料之一，不自动证明改稿导致变化。没有真实咨询/访问数据不计算ROI。
